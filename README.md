# LayoutFixer


**LayoutFixer — Vencord user plugin**
Mainly for Russian speakers.

Adds a button to messages that shows what the text was supposed to be if it was typed in the English layout by mistake (`ghbdtn` → `привет`). The result appears under the message, and the original stays untouched.

Useful when someone forgets to switch layouts and you don't want to copy their message into a converter every time.
